MODEL NOTES

关于这个研究工具

模型基于2016–2022年单中心队列开发，并在2023–2024年受者中进行时间验证。三个结局分别使用10套插补模型的预测概率平均值。本版要求全部变量实测填写，不执行缺失值插补。

时间验证中模型存在平均风险高估，尚需进一步验证并评估再校准。标准化系数不代表因果效应。

查看计算与分组方法

出血量和降钙素原先做自然对数log(1+x)转换，再代入每套模型的原始尺度系数计算概率，最后取10个概率的平均值。风险组使用开发队列第20和80百分位的完整精度切点：预测风险≤下切点为低风险，>下切点且≤上切点为中风险，>上切点为高风险。各结局切点不同。
